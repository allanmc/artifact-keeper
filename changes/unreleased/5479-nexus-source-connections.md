- **A Nexus migration source connects with a trailing-slash URL or a user token, and a failed connection test says why** (#5479). A source URL ending in `/` (for example `https://nexus.example.com/`) made every request go to `//service/rest/...`, which Nexus answers with 404. URLs are now stored without the trailing slash, and both the Nexus and Artifactory clients normalize URLs already saved with one. A Nexus `api_token` connection used to be silently sent with empty credentials. It now authenticates with the Nexus user token as Basic credentials: `credentials.username` is the token's name code and `credentials.token` its passcode. Creating a connection whose credentials do not match its `auth_type`, or whose `source_type` is not `artifactory` or `nexus`, is refused with 400 instead of being saved and failing later. `POST /api/v1/migrations/connections/{id}/test` names the source type in its message rather than always saying "Artifactory", gives the probed URL (credentials redacted) with the HTTP status it returned or the transport error's cause, and logs the failure. The response gains `source_type` and a source-neutral `version`. `artifactory_version` is kept with the same value and is deprecated.
